# Online Voting System (Python)

A simple Online Voting System developed using Python.

## Features
- Voter Registration
- Login Authentication
- Secure Voting
- Result Display
- Graph Visualization using Matplotlib
- Winner Announcement

## Technologies Used
- Python
- SQLite
- Matplotlib

## Setup

Install required libraries:

```bash
pip install -r requirements.txt
```

## How to Run

```bash
python main.py
```
